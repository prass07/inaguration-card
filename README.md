# Inaguration Greeting Card

Welcome to the Inauguration Card project! This interactive card allows users to cut a ribbon and light a candle using animations.

## Demo

![Inauguration Card Demo](video/demo.mp4)

## Features

- **Cut the Ribbon**: Users can cut the ribbon to mark the inauguration.
- **Light the Candle**: Users can light a candle to celebrate the event.
- **Smooth Animations**: Enjoy smooth and engaging animations.

## Installation

To use or modify this project, follow the steps below:

1. **Clone the repository**
   ```sh
   git clone https://github.com/yourusername/inauguration-card.git
   ```
2. **Navigate to the project directory**
   ```sh
   cd inaguration-card
   ```
